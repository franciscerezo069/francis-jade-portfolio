FRANCIS JADE CEREZO — STATIC PORTFOLIO WEBSITE

1. Open index.html in a browser to preview.
2. To publish free: upload this entire folder to a GitHub repository and enable GitHub Pages (Deploy from branch, root), or drag the folder into Netlify Drop.
3. Keep index.html, styles.css, script.js, and assets together.
4. The website has no backend and collects no data. Contact buttons link to the public Upwork profile.
5. Master PDF: assets/master-portfolio.pdf. Five project PDFs and previews: assets/project-1 through project-5.
6. Google Fonts require internet; site otherwise works offline.
7. Project descriptions distinguish fictional sample workflows from the developed Excel personal project.
